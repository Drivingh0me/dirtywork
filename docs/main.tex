\section{Introduction}
Dirtywork is a chess engine that solves for a recommended move and an evaluation of the game in units of pawns advantage.

\section{User Guide}
Dirtywork can be easily run in the terminal with flags.

\subsection{Flags}
\begin{itemize}
\item -f/--file Pass a game file to dirtywork.
\item -d/--debug
\item -m/--memory Set the max memory dirtywork can request.
\item -s/--search Search for fancy magics.
\end{itemize}

\section{Algorithms}
The evaluation algorithm used by dirtywork is Temporal Interdependant Eval, or ``TIE''.
Firstly, TIE determines all legal moves from the root board, these are the fundamentals (f), and the goal is to rank them.
Secondly, TIE looks ahead n depth for all legal moves from the fundamentals.
Once these f1 and children are calculated, a static evaluation is run on all points and they are vertically ranked by a static evaluation engine where higher is better for white.
A path is then drawn where white's move chooses the highest point and black's move chooses the lowest point, for top z f2.
The best x positions for white are then saved and all others are forgotten.
The best value from f2 top child is now used to rank parent f1.
Now that f1 are ranked with detail 1, all f2 of top f1 are treated as f1 was previously.
This repeats until detail n is found for all fundamentals.
Top f1 pass max value to fundamentals and the fundamentals are ranked.

Essentially, a tree is formed from the fundamentals and the children are used to rank the fundamentals.
The top fundamentals are then pushed further and the top grandchildren are used to rank the fundamentals.
These top fundamentals are then pushed and the top great grand children are used to rank the fundamentals, and so on.

\subsection{Depth}
The depth parameter of TIE sets how many times the algorithm is recursivly called.
A higher depth is more expensive, but more accurate.
If we call the depth parameter \textbf{n}, then we can derive the rest of the parameters from this \textbf{n}.
The prune function removes the lowest eval move sequences and leave only the top \(2 + 2\sqrt{n}\) sequences.
Prune is called every \(\sqrt{n + 2}\) moves.

\section{Math}
Dirtywork uses bitboards to store piece locations.
Bitboards ar 64 bit integers wher each bit coresponds to a square on the board.
If the bit is zero, no peice is present, if the bit is 1, a piece is present at that square.

\subsection{Determining the area under a function}
If you want to determine \(\int_a^b x\,dx\) for a line \(x\), simply sum all of the ranked move points \(x_a\) to \(x_b\).
